# 版式与视觉约束

画布：1080×1440（3:4）。白色背景 `#FFFFFF`，标题 `#121212`，辅助文字 `#828282`，浅灰卡片 `#F5F5F7`，蓝色强调 `#348BD4`。左右安全边距建议 80 px。

T01：封面主标题最多 3 行，每行约 6–9 汉字，下部一张大图。
T02：大图约占上半页，底部短标题。
T03：标题最多 2 行，下部单张大图。
T04：一张主图和两张小图。
T05：三步流程，每步含短标题和说明。
T06：2×2 内容卡片。
T07：左右等尺度的真实对比。
T08：纯文字观点、左对齐、最多 4 行，不配图。
T09：三组真实数字与说明。
T10：带有可阅读行距的完整提示词或教程文本。
T11：上部图像，下部结尾互动文案。

所有字数上限以内容可读性为准，不要通过过度缩小字号塞满文本。
